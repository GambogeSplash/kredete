Kredete Brain design system

Tokens first, components second, pages last. Every value you see on a screen comes from tokens.css. This page reads that file live, so it cannot drift from the app.

Color

Neutrals carry the interface. One brand color does the work. Status colors only appear for status.

Typography

One family. Size sets hierarchy, weight stays at 400, 500 and 600.

Spacing

4px grid. Padding and gaps use these steps and nothing in between.

Radius

Cards 12, controls 8, tags 6, sheets 16 and 20. Nest by subtracting the padding.

Motion

Hover a tile. Fast for feedback, base for state changes, slow for sheets. Decelerate on the way in, accelerate on the way out.

Components

Built only from tokens. Use these, do not restyle them. A new look is a named variant.

Rules. 1) Use a token, never a literal, for color, radius, space, type, shadow and motion. 2) One component per job: if two things look different, one is wrong. 3) States are part of the component: hover, focus-visible, active, disabled, loading. 4) Touch first: 40px targets, nothing hover-only. 5) Motion uses transform and opacity, under 320ms, and respects reduced motion.
